# 中国传统色

故宫里的色彩美学 · 384 色 · 24 节气 · 4 季

这是一个零依赖、可直接打开的单页 HTML 工具。页面收录《中国传统色：故宫里的色彩美学》中的 384 种传统色，提供节气色表、应用场景配色、浅色/深色模式、沉浸式选色和 AI 提示词。

## 使用

直接打开根目录的 `index.html` 即可使用，无需安装依赖或启动服务。
